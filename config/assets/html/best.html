★ Cloudflare 优选 IP

多源采集 + 端口白名单 + 多级排序；bestip_probe（vless 健康检查）与 sni_probe（anytls 透传探测）对入口做真实可用性验证。

动态生成

选择端点、客户端、节点协议与落地国家，一键复制优选订阅链接（默认包含全部健康节点）。

三维联动：国家候选只显示配置了所选协议的国家；协议候选 = 客户端支持 ∩ 国家配置（如 Surge 不支持 vless）。筛选参数按端点支持度自动禁用（bestIpKr 强制韩国、不支持 d；bestCfProxySub 需填写 sub 订阅源链接）。如导出为空请检查该国家对应探测是否启用。

订阅端点

格式参数 :format = 客户端 + 节点类型，例如 clashVmess、surgeTrojan、quanxVless、loonAnytls、v2raynVmess。

筛选参数
d 落地国家，如 ?d=US（默认 JP）
c 节点名中的国家代码，如 ?c=US
limit 限制返回数量，如 ?limit=20
sort 排序：country / ip / random，默认固定排序（国家→IP→端口）
random 随机返回，如 ?random=true
cdn 仅保留 CDN 节点，如 ?cdn=true
ipv6 仅保留 IPv6 节点，如 ?ipv6=true
探测语义：vless/vmess/trojan 格式在启用 bestip_probe 时仅导出健康节点；xxxAnytls 格式在启用 sni_probe 时仅导出可透传 anytls 的节点；未启用相应探测时该格式导出为空。
