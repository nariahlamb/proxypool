★ Cloudflare 优选 IP

多源采集 + 端口白名单 + 多级排序；bestip_probe（vless 健康检查）与 sni_probe（anytls 透传探测）对入口做真实可用性验证。

动态生成

选择客户端、节点协议与落地国家，一键复制优选订阅链接（默认包含全部健康节点）。

协议下拉按所选国家自动联动（仅显示该国家已配置的协议）；如导出为空请检查该国家对应探测是否启用。
订阅端点

格式参数 :format = 客户端 + 节点类型，例如 clashVmess、surgeTrojan、quanxVless、loonAnytls、v2raynVmess。

筛选参数
d落地国家，如 ?d=US（默认 JP）
c节点名中的国家代码，如 ?c=US
limit限制返回数量，如 ?limit=20
random随机返回，如 ?random=true
cdn仅保留 CDN 节点，如 ?cdn=true
ipv6仅保留 IPv6 节点，如 ?ipv6=true
探测语义：vless/vmess/trojan 格式在启用 bestip_probe 时仅导出健康节点； xxxAnytls 格式在启用 sni_probe 时仅导出可透传 anytls 的节点；未启用相应探测时该格式导出为空。
